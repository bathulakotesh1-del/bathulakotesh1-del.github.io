My Projects

🔥 Fire Fighter Robot Using Arduino

Developed an autonomous fire-fighting robot using Arduino UNO to detect flames through flame sensors and activate a water pump for fire suppression. Integrated an ESP32-S module for Bluetooth based manual control and an ESP32-CAM for live visual monitoring. The system supports both automatic and manual operation, combining sensor interfacing, motor control, wireless communication and real-time monitoring.

  • Arduino UNO
  • Flame Sensors
  • L298N Motor Driver
  • Relay & Water Pump
  • ESP32-S Bluetooth Control
  • ESP32-CAM Live Monitoring

💡 Automatic Night Light Control System

Designed and developed an automatic night-light circuit using an LDR and 555 Timer IC to detect changes in surrounding light conditions and control an LED automatically. The project involved practical circuit design, sensor interfacing and electronic component selection to achieve automatic lighting without manual switching.

  • LDR
  • 555 Timer IC
  • Resistors
  • LED

🚗 Smart Accident Detection System

Developed an embedded accident detection system using an Arduino UNO, accelerometer and GSM module to identify sudden vehicle impacts and automatically send emergency SMS notifications to predefined contacts. The project focuses on real-time sensor monitoring, threshold-based event detection and GSM communication for faster emergency notification.

  • Arduino UNO
  • Accelerometer
  • GSM Module
  • Crash Detection
  • Emergency SMS
